Project Overview

Description

Transportation Billing Automation is a Chrome Extension created to eliminate repetitive administrative work associated with transportation billing.

The extension retrieves transportation trip data, validates required fields, formats billing records, and automates repetitive tasks that previously required hours of manual processing.

By automating these workflows, the extension greatly improves efficiency while reducing human error and increasing billing accuracy.
