Description

The Artist Showcase web application is a full-stack MERN project that allows users to explore and interact with a collection of artists. Users can create accounts, log in securely, and browse artist profiles while marking their favorites. Administrators have full control over the platform, with the ability to create, update, and delete artist entries, as well as manage associated data. The application features a responsive and visually appealing interface with a custom-designed theme, providing both functionality and an engaging user experience.

Skills Learned

  • Developed a full-stack application using MongoDB, Express.js, React, and Node.j
  • Implemented user authentication with JWT and password hashing using bcrypt
  • Created a responsive UI with custom CSS styling and animations
  • Built role-based access control for admin and standard users
