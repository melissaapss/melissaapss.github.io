Featured Project

MERN Stack Website

A full-stack Artist Showcase application built with MongoDB, Express.js, React, and Node.js.

Description

The Artist Showcase web application is a full-stack MERN project that allows users to explore and interact with a collection of artists. Users can create accounts, log in securely, browse artist profiles, and mark artists as favorites.

Administrators have full control over the platform, including the ability to create, update, and delete artist entries and manage associated data. The application also features a responsive interface and a custom-designed visual theme.
