Project Overview

Description

The Artist Showcase web application is a full-stack MERN project that allows users to explore and interact with a collection of artists. Users can create accounts, log in securely, browse artist profiles, and mark their favorite artists.

Administrators can create, update, and delete artist entries while managing related information through a dedicated dashboard. The application includes a responsive interface and a custom visual theme.

Project Highlights

  • Secure JWT authentication
  • Password hashing with bcrypt
  • Artist favorites system
  • Administrative CRUD dashboard
  • Role-based permissions
  • Responsive user interface
