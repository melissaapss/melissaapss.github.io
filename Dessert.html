Project Overview

Description

The Artist Showcase web application is a full-stack MERN project that allows users to explore and interact with a collection of artists. Users can create accounts, log in securely, browse artist profiles, and mark artists as favorites.

Administrators have full control over the platform, including the ability to create, update, and delete artist entries and manage associated data.

Project Highlights

  • Secure JWT authentication
  • Encrypted passwords using bcrypt
  • Artist favorites system
  • Administrative CRUD dashboard
  • Role-based user permissions
  • Responsive custom interface
