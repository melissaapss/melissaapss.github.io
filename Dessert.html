Featured Project

Artist Showcase

MERN Stack Website

An interactive full-stack application with secure authentication, artist management, favorites, and role-based access.

Description

The Artist Showcase web application is a full-stack MERN project that allows users to explore and interact with a collection of artists. Users can create accounts, log in securely, browse artist profiles, and mark their favorite artists.

Administrators have full control over the platform, including the ability to create, update, and delete artist entries and manage associated data. The application features a responsive interface and a custom-designed visual theme.

Technologies Used

  • MongoDB
  • Express.js
  • React
  • Node.js
  • JWT
  • bcrypt
  • CSS3
  • Role-Based Access
