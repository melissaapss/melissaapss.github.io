Description

The Artist Showcase web application is a full-stack MERN project that allows users to explore and interact with a collection of artists. Users can create accounts, log in securely, browse artist profiles, and mark their favorites.

Administrators have full control over the platform, with the ability to create, update, and delete artist entries, as well as manage associated data. The application features a responsive interface and a custom-designed visual theme.

Skills Learned

  • Developed a full-stack application using MongoDB, Express.js, React, and Node.js
  • Implemented user authentication with JWT and password hashing using bcrypt
  • Created a responsive interface with custom CSS styling and animations
  • Built role-based access control for administrators and standard users
