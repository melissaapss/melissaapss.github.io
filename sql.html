Project Overview

Description

The Airline Database is a relational SQL project designed to manage flights, passengers, bookings, aircraft, airports, and employees. The database uses clearly structured tables connected through primary and foreign keys.

SQL queries were created to retrieve flight schedules, passenger manifests, booking histories, and operational reports. Joins, aggregate functions, filters, and subqueries were used to answer more complex database questions.

Project Highlights

  • Primary and foreign keys
  • Normalized table structure
  • Complex SQL joins
  • Aggregate functions
  • Data integrity constraints
